# v3.25 进图事件提醒

**作者：** 周建豪  
**日期：** 2026-10-22  
**进度：** 已完成

## 目标

玩家从别的地图走进（或战斗后回到）正在发生异象 / 小事件的地图时，除了 HUD 小字外，再给一句 toast，避免「进来了但不知道这儿有事」。

## 规则

| 条件 | Toast |
|------|--------|
| 本图有进行中异象 | `此地异象「…」：目标进行中 / 已得信物…（剩约 N 步）` |
| 本图有进行中小事件 | `此地正逢【…】：操作提示（剩约 N 步）` |
| 两者同图 | 先异象后小事件（Toaster 自动错开） |
| 时机 | 地图名横幅将落时（进图约 1.6 秒后） |

文案集中在 `EventHints.enterEventToasts`；`WorldScene.create` 延迟调用。
