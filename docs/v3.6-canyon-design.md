## 1. 怎么走

第三章打完林语鹿后，回音林北段东边的山路打开（`canyon_unlocked`）。

```mermaid
flowchart LR
  回音林 --> 千岩峡谷
  千岩峡谷 --> 锤音镇
  千岩峡谷 --> 旧矿道
  锤音镇 -->|怪力手套| 推石
  推石 --> 矿车
  矿车 -->|LRL| 砧
  砧 --> 磐角犀
```

峡谷从南往北必须按顺序推开三处，不能绕：

| 区 | 做法 | 打开 |
|---|---|---|
| 1 | 把石头向北推进裂缝 | (10,10) |
| 2 | 两块石头分别压上两块踏板 | 石门 (10,6) |
| 3 | 三块石头推进北墙裂缝 | 通往矿道 |

入口木牌可以把石头推回原位。水面和岩石的骑乘能力过不了这些墙。

## 2. 矿车

三个道岔默认都朝左（L）。面朝道岔按确认会左右调换。

| 路线 | 结果 |
|---|---|
| LRL | 矿道深处，遇见砧 |
| LLL | 好伤药 ×2（只拿一次） |
| RRR | 引兽铃（只拿一次） |
| 其他 | 撞上缓冲木，停在原地 |
