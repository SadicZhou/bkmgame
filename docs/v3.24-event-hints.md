# v3.24 小事件提示打磨（告示板 / HUD / toast）

**作者：** 周建豪  
**日期：** 2026-10-22  
**进度：** 已完成

## 目标

流浪商人、强壮群、训练家集会等小事件落地后，玩家在告示板与地图 HUD 上仍只能看到笼统一句。本轮把「在哪、剩多久、该干什么」说清楚，并在事件消退时给一句 toast。

## 改动

| 位置 | 行为 |
|------|------|
| `EventHints.ts` | 统一 `minorBoardLine` / `minorHudLine` / 开始·结束 toast |
| 旅人告示板 | 按种类附加操作提示（找「商」、再战翻倍焰币、强壮四成等） |
| 大地图 HUD | 异象行下方追加 `◇ 事件名·此地/地图 · 剩N步` |
| 步进反馈 | `minorStarted` 用更具体 toast；`minorEnded` 不再静默，弹出收摊/散场等 |
