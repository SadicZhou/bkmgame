## 二、浏览器验证（功能流程）

| 编号 | 场景 | 步骤 | 预期 |
|------|------|------|------|
| E-01 | 第一章收尾 | 设置队伍，开熔鬃狮战并取胜 | 显示通关提示 → 「第一章完」章节卡（含焰之徽记）→ 回到余烬山道，**不进入 Ending** |
| E-02 | 解锁湖畔 | E-01 后去青苔草地南口 | 传送到雾泉湖畔，地名提示正确 |
| E-03 | 未解锁 | 新存档走到草地南口 | 显示锁定提示，不传送 |
| E-04 | 旧存档 | 写入只有 boss_beaten 的存档后读档 | 进入世界时提示一次「获得焰之徽记…」，南口可通行 |
| E-05 | 湖畔地图 | 进入湖畔，晴 / 雨 / 雾 / 夜晚各截图 | 地砖、水面动画、冰面、码头、灯台（罩着状态）正常显示，无穿帮 |
| E-06 | 节拍 1-2 | 与泉守汐对话 | 剧情台词，背包出现「旧钓竿」（重要物品分类，不能出售） |
| E-07 | 钓鱼成功 | 面朝水面按确认，「！」出现后立即按确认（rng 固定成功） | 进入野生战，对手是泡泡鱼或雾泉螈 |
| E-08 | 钓鱼过早 | 甩竿后立刻按确认 | 「还没咬钩……」，可以马上再钓 |
| E-09 | 钓鱼超时 | 「！」出现后不按 | 「鱼溜走了」，可以马上再钓 |
| E-10 | 非水面 | 面朝草地按确认 | 不触发钓鱼（正常交互/无反应） |
| E-11 | 斥候出现 | 第一次钓鱼战结束后 | 码头出现两名熄灯会斥候 |
| E-12 | 连战胜利 | 与斥候甲对话并取胜 | 不回血，直接进入斥候乙的开场台词和战斗；两场都赢后写入两个旗标 |
| E-13 | 连战失败 | 甲赢、乙输 | 回旅人小屋；`scout1_beaten` 被清除，再次挑战从甲开始 |
| E-14 | 浮桥 | 连战胜利后与泉守汐对话 | 雾泉螈搭桥演出，桥格变为可走，能走到湖心岛 |
| E-15 | 沧澜鲸 | 与湖心沧澜鲸对话开战并取胜 | 不可逃跑；胜利后提示潮之徽记 + 好钓竿，灯台亮起，随后进入 Ending |
| E-16 | 好钓竿 | 结局后回到世界（或刷新读档）再钓鱼 | 使用好钓竿表（珊冠鱼 / 澜鳍螈 / 碧波龟） |
| E-17 | 徽记加成 | 持焰之徽记，用焰招式攻击固定对手，对比无徽记的伤害 | 平均伤害约 ×1.1 |
| E-18 | 冰面 | 在冰面来回走 | 只遇到霜粒鹅 |
| E-19 | 新伙伴立绘 | 图鉴 / 战斗中查看 5 个新伙伴 | 立绘正常，透明背景无洋红残边，风格明亮 |
| E-20 | 进化 | 泡泡鱼升到 16 级 | 进化为珊冠鱼 |
