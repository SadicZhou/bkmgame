## 2. 一键回归 · 慢速真实出招模式

- 入口：`http://127.0.0.1:45321/?regress=slow` 或双击 `scripts\run-regress-slow.bat`（快速模式仍为 `?regress=1`）。
- 队伍贴近第一章通关时的进度：涌潮龟 Lv15、森冠狐 Lv14、砾团犬 Lv13；背包伤药 ×6、好伤药 ×3；每个步骤开始前回满（相当于回过小屋）。
- 驱动 `src/dev/autoBattle.ts`，通过真实的指令菜单操作：
  - 在场伙伴 HP < 35% 且有药 → 「道具」→ 选药 → 选自己（好伤药优先）；
  - 否则选 威力 × 属性克制 × 本系 1.2 最高的攻击招式；
  - 学招面板出现时选第一行，保证流程不中断。
- 每场战斗写入该步骤说明：`胜/负 N 回合，用药 M（敌 Lv…；剩余 伙伴 Lv HP）`。剩余 HP 在结算前记录（全灭结算会回满）。
- 输掉的战斗会让该步骤失败，后续步骤跳过。**这本身就是数值信号**，见第 4 节。

## 3. 钓鱼大赛扩展

### 3.1 澈的纪录（最佳记录排行）

| 规则 | 值 |
|------|------|
| 澈的纪录 | 各物种 基准体长 × 1.2（泡泡鱼 21.6 / 雾泉螈 31.2 / 珊冠鱼 38.4 / 澜鳍螈 48 / 碧波龟 36 / 雾灯鳐 66 cm） |
| 打破 | 玩家该物种最大体长 > 澈的纪录（正常体长上限 1.3 倍，可以打破；强壮个体更容易） |
| 奖励 | 找澈对话一次结清：每打破一种 80 焰币；旗标 `fish_rec_<物种>` 防重复 |
| 提示 | 钓到时出现「超过了澈的纪录（X cm）！去给他看看吧」 |
| 钓鱼记录面板 | 打破的物种名前显示 ★；说明栏显示「澈的纪录 X cm（已打破 ★）」；标题右侧显示「已钓 / 破纪录数」 |

对话优先级：集齐大奖 → 打破纪录领奖 → 当天大赛（领奖 / 进行中 / 出题）。

### 3.2 雨天限定题

| 规则 | 值 |
|------|------|
| 触发 | 当天第一次找澈出题时，雾泉湖畔正在下雨 |
| 题目 | 题库与普通题相同；目标体长 = 基准 × 1.0（比普通题的 1.1 宽松） |
| 达标条件 | **必须在下雨时钓到**（`FishContest.rain = true`，判定时检查当前天气） |
| 奖励 | 300 焰币 + 引兽铃（普通题：200 焰币 + 轮换道具） |
| 雨停了 | 澈提示「等下次下雨再钓吧，今天之内都算数」 |

旧存档里的题目没有 `rain` 字段，按普通题处理。

## 4. 数值发现：沧澜鲸偏难（待决定）

慢速回归连续 3 次都在沧澜鲸处团灭；`SIM=1` 模拟（每档 200 场，只出招 / 带药）：

| 队伍（首发 / 次发 −2 / 砾团犬 −3） | Lv16 | Lv18 | Lv20 | Lv22 |
|------|:--:|:--:|:--:|:--:|
| 炽角兔 + 森冠狐（无药） | 12% | 33% | 64% | 88% |
| 涌潮龟 + 森冠狐（无药） | 7% | 36% | 75% | 99% |
| 森冠狐 + 雾泉螈（无药） | 8% | 26% | 69% | 92% |
| 带药（3 好伤药 + 6 伤药） | 3～9% | 14～42% | 47～75% | 70～94% |

- 按正常流程推进（不刻意练级），到湖心时首发约 Lv18～19，胜率只有 25～40%；带药也不会更好，因为鲸每回合造成的伤害高于伤药回复量。
- 可选方案：① 沧澜鲸降到 Lv18；② 保持 Lv20，下调攻击种族值 18 → 15；③ 维持现状，在泉守汐台词里提示「建议 Lv20 以上」。**需要你决定**。
