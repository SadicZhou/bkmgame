# 焰迹旅人 · 伙伴立绘美术规范

> 作者：周建豪　｜　更新：2026-10-14　｜　进度：全部 29 种伙伴立绘已完成（含异色，共 58 张）；场景背景 7 张、地图装饰物 9 件、玩家行走图与 9 位 NPC 已完成；地图块与天气特效由代码绘制（见第五节）

## 一、总原则：底线统一，基调自由

风格**不定死**。每只伙伴可以按自己的设定选基调，可爱、帅气、霸气都行，进化后也不一定都要变霸气，比如可以有越进化越萌的伙伴。
只需守住下面几条**共同底线**，整套图放在一起才不会"串画风"。

### 共同底线（所有伙伴必须满足）

| 项 | 要求 |
|---|---|
| 画法 | 16-bit 像素画，1px 深色描边，柔和赛璐璐阴影 |
| 色调 | 明亮、饱和、正向；整体不发黑、不阴森 |
| 气质 | 再霸气也是"正派 / 守护者"，**不要邪恶感** |
| 禁用元素 | 大面积黑色铠甲、熔岩裂纹皮肤、獠牙外露的狰狞脸、发光怒目、恶魔角、骷髅、血腥 |
| 构图 | 单只全身、居中、正面或 3/4 视角，无文字 |
| 背景 | 纯洋红 `#FF00FF` 平涂（供脚本抠图）；角色本身尽量避免大面积洋红或紫粉色 |
| 原创性 | 禁止模仿宝可梦等现有 IP 的具体角色造型 |

### 三种基调（按物种自由选择）

| 基调 | 神态 | 体态与装饰 | 适合 |
|---|---|---|---|
| **可爱** | 大圆眼、腮红、微笑 | 圆滚、短手短脚、小装饰 | 一阶、常见小动物、治愈系 |
| **帅气** | 挑眉、自信笑、眼神清亮，不加腮红 | 修长、动态姿势（奔跑 / 抱臂 / 架势）、围巾或叶片之类飘带 | 二阶、敏捷型、对手型 |
| **霸气** | 坚定、威严，但不凶恶 | 高大、强壮、披风 / 冠 / 光环 / 属性特效环绕 | 三阶、守护兽、唯一伙伴、头目 |

同一条进化链建议**保留辨识特征**（主色、标志部件，比如兔耳和角、龟壳涡纹、叶尾），让玩家一眼认出是同一只的进化。

## 三、出图提示词模板

```text
Single creature sprite, high quality 16-bit pixel art like official monster-collecting RPG sprites,
crisp 1px dark outline, bright saturated colors, soft cel shading.
[基调描述：cute / cool / majestic heroic] [物种外形、主色、标志部件、姿势、表情]
NOT evil, no dark armor, no fangs, no dark colors.
Full body, centered, three-quarter front view, no text.
Background: flat solid pure magenta #FF00FF, no gradient, no shadow on background.
```

- 进化形态要把**进化前形态的原图**作为参考图，以保持配色和特征。
- "帅气"基调可以加 `confident smirk, heroic eyebrows, no blush`；"可爱"基调可以加 `big sparkly eyes, pink blush`。

## 四、入库流程

1. AI 原图存为 `art-src/creatures/<物种id>.jpg`。
2. 运行 `python scripts\process-sprites.py`：抠洋红背景、裁边、缩放到 144×144，并自动生成 `-shiny` 异色版。
3. 把物种 id 加进 `src/game/graphics/CreatureArt.ts` 的 `ART_SPECIES`。
4. 在深色背景下检查抠图边缘和异色效果，再进游戏看战斗画面（二阶 ×1.1、三阶 ×1.2 会自动放大）。

## 五、场景、装饰物与人物

同样遵守"明亮、正派"的底线，提示词沿用上面的像素风描述和纯品红背景。

| 类别 | 原图位置 | 处理脚本 | 输出规格 | 接入位置 |
|------|----------|----------|----------|----------|
| 场景背景 | `art-src/backgrounds/` | `scripts/process-backgrounds.py` | 战斗 640×360，其余 640×480，JPG | `graphics/SceneArt.ts` |
| 地图装饰物 | `art-src/decor/` | `scripts/process-decor.py` | 按游戏内宽度缩放（32px = 1 格），PNG | `data/decor.ts`（位置、占格、是否挡路、动效） |
| 人物行走图 | `art-src/chars/` | `scripts/process-chars.py` | 每帧 32×40，脚底对齐，排成一行 | `graphics/CharArt.ts`（NPC id → 帧号） |

- **装饰物**：可以把多件物件画在一张图里并排摆放，在脚本的 `SHEETS` 里按从左到右登记，脚本会自动切开并去掉邻居碎片。
- **人物**：玩家图是 4 行（下、上、左、右）× 3 列（站立、迈左脚、迈右脚）的网格；NPC 图是 3×3 网格，全部朝前。同一张图的所有格子共用一个裁剪框，保证帧间不抖动。
- **新增 NPC**：在 NPC 合图里加一格，重新运行脚本，再在 `CharArt.ts` 的 `NPC_FRAME` 里登记帧号；没登记的 NPC 会自动使用代码绘制的着色小人。第一张合图满了以后用第二张 `char-npcs2`（v3.1：斥候澄、斥候漆、钓鱼少年澈，登记在 `NPC2_FRAME`）。
- **v3.1 新增**：湖畔战斗背景 `bg-battle-lake`；装饰合图 `lakeprops`（灯台熄灭 / 灯台点亮 / 芦苇）；沙地、冰面、码头、浮桥地砖在 `graphics/tiles/LakeTiles.ts` 中绘制。熄灯会斥候是"被误导的普通人"，用深蓝斗篷，不画成反派脸。
- **地图块与天气**不出图：地图块在 `graphics/tiles/` 里逐像素绘制（`PixelPen` 带固定随机种子，每次生成结果相同），天气在 `ui/weather/` 里用 Phaser 粒子实现。
